Devstia-VM v2.X.X builds Intel/AMD x86 or Apple Silicon/ARM64 64bit Debian 12.X with HestiaCP, HestiaCP Pluginable, and leading HCPP Plugins into a single, compressed qcow2 VM image for redistribution as multipart .tar.xz files. Supported build environments are currently macOS on Intel and Apple Silicon; with target runtime support for Apple and Windows. 

Use the build.sh to create the multipart image files that will appear in the build subfolder.
